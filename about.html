关于秦时食序

「秦时食序」是一个以二十四节气为时间线，以陕西美食为线索的交互式网页设计项目。

我们从关中、陕北、陕南三大地域出发，沿着春夏秋冬的更迭，带你在地图上寻找时令美食，点亮专属的秦味集卡册。

通过八道题的美食人格测试，我们希望能帮你找到性格里最契合的那一味陕西。也欢迎你在探索坊里，记录下属于你的美食留念。

项目名称： 秦时食序 · 循四时之序，品三秦之味

团队名称： 专业团队

团队成员： 李孟钰雯、王笑冉、张哲明

前端技术： HTML5 / CSS3 / JavaScript

项目展示： GitHub Pages 在线预览与源码托管

数据来源： 陕西地方饮食文化资料整理

感谢你的探索与体验。
